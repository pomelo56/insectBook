# 昆虫发现成就小程序

一款面向中小学生的昆虫发现成就小程序，帮助用户记录和展示自己发现的昆虫。

## 功能特点

- 📸 **拍照识别**：通过百度AI图像识别API自动识别昆虫种类
- 📚 **图鉴收集**：记录用户发现的昆虫，并实时统计完成度
- 🔍 **图片缩放**：支持双指缩放图片，确保昆虫位于画面主体位置
- 📱 **简洁界面**：专为中小学生设计的友好界面

## 技术栈

- 微信小程序开发
- 云开发（云函数、云数据库）
- 百度AI图像识别API

## 核心文件结构

```
miniprogram/
├── pages/
│   ├── index/           # 首页：图鉴收集进度
│   └── camera/          # 拍照识别页
├── images/              # 图标、背景图等静态资源
├── app.js               # 应用入口文件
├── app.json             # 全局配置
└── app.wxss             # 全局样式

cloudfunctions/
├── calliNat/            # 云函数：调用百度AI识别API
└── markFound/           # 云函数：保存昆虫发现记录
```

## 数据库结构

项目使用云开发的两个集合：

1. **insects**：存储昆虫基本信息
   - _id：昆虫唯一ID
   - name：昆虫名称
   - category：昆虫属类
   - habitat：常见发现地域
   - food：喜爱食物
   - description：昆虫描述
   - imageUrl：图片URL
   - ...

2. **user_insects**：存储用户发现记录
   - _openid：用户唯一标识
   - insectId：昆虫ID
   - name：昆虫名称
   - foundCount：发现次数
   - firstFoundTime：首次发现时间
   - lastFoundTime：最近发现时间

## 使用说明

1. 打开小程序，进入首页查看当前图鉴收集进度
2. 点击底部导航栏的"发现昆虫"按钮进入拍照页面
3. 拍摄昆虫照片或从相册选择图片
4. 系统自动识别昆虫，展示识别结果
5. 选择正确的结果，点击"确认发现"保存记录
6. 返回首页查看更新后的图鉴进度

## 注意事项

- 请确保您已开通微信云开发环境，并将环境ID配置到app.js中
- 请在云函数环境变量中配置百度AI的API Key和Secret Key
- 识别结果仅供参考，可能存在一定误差
- 为获得更好的识别效果，请确保图片清晰，昆虫位于画面中央
